# Paradise Nursery

Paradise Nursery is a responsive plant-shopping application built for discovering and shopping for houseplants. Browse a curated collection by category, add plants to a Redux-powered cart, adjust quantities, and review your order total.

## Main features

- Welcoming, nature-inspired landing page with responsive navigation
- About page describing the company, mission, and vision
- Plant catalog grouped into meaningful categories
- Add plants to the cart without creating duplicate entries
- Increase, decrease, or remove cart items with totals recalculated immediately
- Responsive shopping cart with an empty state and checkout confirmation
- Client-side routing between Home, Shop, Our Story, and Cart

## Technologies used

- React and JavaScript (JSX)
- Vite
- Redux Toolkit and React Redux
- React Router DOM
- CSS3

## Installation

Install [Node.js](https://nodejs.org/) and npm, then open a terminal in the project directory and run:

```bash
npm install
```

## Run the application

Start the local development server:

```bash
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`) in your browser.

To create and preview a production build:

```bash
npm run build
npm run preview
```
